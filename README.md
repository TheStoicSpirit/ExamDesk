## 📖 About ExamDesk

ExamDesk is an offline-first examination management application designed to simplify the everyday examination workflow of teachers and educational institutions.

From maintaining a question bank to generating examination papers, printing OMR sheets and evaluating student responses, ExamDesk brings everything together in one place.

Whether you teach at a school, run a coaching centre or conduct independent examinations, ExamDesk helps you spend less time managing paperwork and more time teaching.

**No complicated setup. No mandatory accounts. No dependence on the internet for everyday work.**

## ✨ Features

| Feature | Description |
|:---|:---|
| 📚 **Question Bank** | Maintain a reusable question bank in English and Hindi. Supports mathematical expressions, images, answer notes and JSON imports. |
| 📝 **Question Papers** | Generate professionally formatted question papers with customizable layouts, one or two columns, school branding and automatic page breaks. |
| ✅ **Answer Keys** | Generate separate answer keys for every question paper with customizable layouts. |
| 🔵 **OMR Sheets** | Create printable OMR answer sheets in full-page or half-page formats. |
| 📷 **Automatic OMR Evaluation** | Scan photographs, PDFs or live camera captures of filled OMR sheets. Detect responses, flag doubtful markings and calculate scores automatically. |
| ✍️ **Written Answer Evaluation** | Enter marks for descriptive answers and combine them with objective examination scores. |
| 📊 **Results & Reports** | View student-wise results, class performance, marks lists and printable report cards. |
| 🌐 **Hindi Typing** | Type Hindi using English letters with built-in transliteration. No internet connection required. |
| 🔒 **Offline & Private** | Keep your questions, examination papers and student records on your own device. No mandatory account or cloud storage. |

> **Note:** Automatic OMR evaluation requires a valid licence. Other core examination-management features are available without a licence.

### Windows Installation

1. Download the latest `.exe` installer.
2. Run the installer and follow the installation instructions.
3. Windows SmartScreen may display a **Windows protected your PC** warning because the application is not signed with a paid code-signing certificate.
4. Select **More info → Run anyway** if you have downloaded the installer from the official release page.
5. Launch ExamDesk from the Start menu or desktop shortcut.

### Android Installation

1. Download the latest `.apk` file.
2. Open the downloaded file.
3. Allow installation from your browser or file manager when Android requests permission.
4. If Google Play Protect displays a warning, verify that you downloaded the APK from the official release page before proceeding.
5. Complete installation and launch ExamDesk.

## 🚀 Getting Started

1. **Build your question bank:** Add questions manually or import an existing JSON question bank.
2. **Create an examination:** Select questions and configure the examination settings.
3. **Generate documents:** Create your question paper, answer key and OMR sheets.
4. **Conduct the examination:** Print the documents and distribute them to students.
5. **Evaluate responses:** Upload filled OMR sheets and review automatically detected answers.
6. **Review results:** Enter descriptive marks where required and generate student-wise reports.

## 🔑 Licensing

ExamDesk follows a simple licensing model.

You can use ExamDesk without purchasing a licence. However, certain premium features require activation.

| Feature | Without Licence | With Licence |
|:---|:---:|:---:|
| Question Bank | ✅ | ✅ |
| Question Paper Generation | ✅ | ✅ |
| Answer Key Generation | ✅ | ✅ |
| OMR Sheet Generation | ✅ | ✅ |
| Automatic OMR Evaluation | ❌ | ✅ |
| Unlicensed Watermark | Visible | Removed |

### Activating Your Licence

1. Open the **About** page in ExamDesk.
2. Locate the **Licence** section.
3. Enter your licence key. It begins with `EXD1.`.
4. Press **Activate**.
5. Connect to the internet for initial activation.

### Important Information

- Your licence is intended for use on your own devices.
- You can activate the same key again on your other devices.
- Your registered name may appear on documents generated with your licence.
- Keep your licence key private. Sharing keys can result in their withdrawal.
- ExamDesk periodically verifies licence validity online. Connect to the internet occasionally for these checks.
- Your regular examination workflow remains available offline.

## 🔄 Updates

ExamDesk automatically checks for newer versions approximately once a day.

You can also manually check for updates:

**Settings → This device → Check for updates**

When an update is available, ExamDesk provides a download option.

Install the newer version over your existing installation. Your existing questions, papers and results are retained.

**Recommended:** Create a backup before installing updates.

Navigate to:

**Settings → This device → Back up now**

## 🔒 Your Data and Privacy

Your data belongs to you.

ExamDesk is designed to keep your examination data locally on your device.

- **Local storage:** Your questions, papers and results remain on your device.
- **No mandatory accounts:** You don't need to register or sign in.
- **Automatic backups:** Windows creates daily backups of your application data.
- **Offline functionality:** Most features work without an internet connection.
- **No cloud storage:** Your examination data is not automatically uploaded to an external server.

### When Does ExamDesk Use the Internet?

ExamDesk only requires internet access for specific operations:

| Operation | Purpose |
|:---|:---|
| Update Checks | Checks GitHub for newer application versions. |
| Licence Verification | Verifies licence validity using its associated random identifier. |
| Initial Activation | Activates your licence key. |
| Optional Translation | Sends the selected text to the translation service when you use a Translate feature. |

Apart from these operations, your regular examination workflow does not require internet access.

### Where Is My Data Stored?

On Windows, application data is stored in a regular folder, by default:

`Documents\ExamDesk`

You can change the storage location from the application settings.

Make regular backups to protect your examination records.

## ❓ Frequently Asked Questions

**Does ExamDesk require an internet connection?**

No. ExamDesk is designed to work offline. Internet access is required for initial licence activation, periodic licence verification, update checks and optional online translation.

**Can I use ExamDesk on both my laptop and phone?**

Yes. Your licence can be activated on your own devices using the same key.

**What happens when I purchase a new computer?**

Install ExamDesk on your new device, activate your licence again and transfer your existing data folder or restore a backup.

**Can I import existing questions?**

Yes. ExamDesk supports importing question banks through JSON files.

**Can I export examination papers?**

Yes. Question papers can be exported to PDF and Word formats. Results can also be exported to CSV.

**Does automatic OMR checking work without a licence?**

No. Automatic OMR evaluation is a licensed feature. You can still generate and print OMR sheets without a licence.

**How can I report a problem?**

Use the GitHub Issues section of the repository, if enabled, and include your ExamDesk version, operating system and a description of the problem.
